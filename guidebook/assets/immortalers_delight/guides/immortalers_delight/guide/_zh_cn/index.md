# 千古乐事

欢迎阅读千古乐事指南。本模组为农夫乐事扩展了古代作物、特色食材、考古遗迹、装备和烹饪内容。

## 入门

嗅探兽是寻找许多古代种子的关键。带它前往不同群系并让它挖掘。作物种类和种植条件可查看[古代作物](crops.md)。

探索[考古遗迹](exploration.md)，寻找可疑方块与其他发现。收集食材后，可以使用农夫乐事的烹饪方块或[魔凝机](cooking.md)制作料理。

模组还加入了[装备与嗅探兽工具](equipment.md)，以及食物效果和可选的[超凡模式](effects.md)。

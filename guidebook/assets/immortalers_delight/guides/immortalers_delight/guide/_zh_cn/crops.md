# 古代作物

许多种子可以由嗅探兽在特定群系挖掘获得。下表的群系信息依据模组介绍。不同作物的种植条件各异，请同时查看物品描述和 JEI 中的当前版本信息。

| 作物 | 种子或果实的获取地点 | 种植说明 |
| --- | --- | --- |
| 白垩玉黍 | 平原 | 种植在耕地上。 |
| 棱蕉 | 丛林 | 三格高的果树，种植在泥土类方块上。 |
| 姬海棠 | 森林 | 种植在耕地上。灌木可以催生成树。 |
| 溪竹 | 河流 | 水生植物，种植在水面下一格的泥土类方块上。 |
| 瓦斯麦 | 绯红森林 | 可种在耕地、灵魂沙或灵魂土上。成熟植株会释放危险气体。 |
| 古苜蓿 | 多种地形 | 种植在耕地上，会像野草一样蔓延。 |
| 诡怨桂 | 诡异森林 | 种在灵魂沙或灵魂土上，成熟时可将附近的水转化为怨泉。 |
| 通天菅 | 山地群系 | 种植在泥土类方块上。 |
| 烬烟杆 | 下界荒地 | 种植在下界岩上。成熟后可吸收附近熔岩并转化为烬烟木。 |
| 冰蛟果 | 冰刺之地 | 种子种在仙人掌顶部。成熟时会释放小型雪暴。 |
| 氧葡萄 | 海底神殿 | 水生植物，在水中生长。 |
| 既望莲 | 森林 | 种植在耕地上。生长时会消耗养分并使土地退化。 |
| 曜石胡桃 | 玄武岩三角洲 | 种在下界岩、灵魂沙或灵魂土上，生长缓慢。 |

模组介绍还列出平原住宅和樱花树遗迹。嗅探兽挖掘和遗迹内容详见[探索与考古](exploration.md)。
